# Exercise-name glossary: Greek (`el`)

The terms `catalogue/i18n/el.json` uses, so the same English word reads the same way across the
catalogue. Names are stored lower-case like the English ones (the app capitalises them). Keep
`v. 2`, numbers, degrees and proper names (Arnold, Zercher, Pallof, Jefferson, Zottman, Scott,
Smith, Bosu, Sanskrit pose names) as they are.

Word order: the movement first, then how you do it, then the equipment. Position words agree
with the movement (`καθιστές πιέσεις`, `καθιστό κάθισμα`).
